---
description: The year-end lease note numbers for one entity under AASB 16 or NZ IFRS 16, by paragraph.
---

Run `npm run lease -- disclosure --entity=<code>` (the latest year end) or `--year=<YYYY>` (the year that ends in that year).

Present each number with its paragraph. Then run `/draft-disclosure` if the operator wants the note written up. Check `attention` first: an unrecorded review or unapproved measurement means the year-end numbers are not final.
