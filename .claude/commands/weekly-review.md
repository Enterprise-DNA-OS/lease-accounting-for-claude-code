---
description: The Monday lease note (critical dates, reviews waiting, rule breaches and the balance sheet today), written up.
---

Run `npm run lease -- weekly-review --json`.

Write a one-page note for the finance and property meeting:
1. **Next 90 days:** option deadlines, reviews, expiries and guarantees, with the owner of each.
2. **Reviews waiting:** each one with the rent it replaces and how many days it has been in effect.
3. **Rule breaches:** the count by rule and the three to fix first.
4. **Balance sheet today:** lease liability (current and non-current) and right-of-use assets per entity, in its currency.

End with three actions for this week, each naming a person. Save it to `drafts/weekly-review-<date>.md`.
