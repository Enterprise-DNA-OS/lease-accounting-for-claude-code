---
description: Every option on every lease, with the last day to exercise it, whether it is in the lease term, and the decision.
---

Run `npm run lease -- options` (`--entity=<code>` for one entity).

Present undecided options soonest first, then decided ones. Flag any last day within 90 days with no decision, and any Victorian retail lease where the landlord's section 28 notice is not recorded.
