---
description: Draft the letter to the landlord exercising an option. Never sends.
---

Run `npm run lease -- draft-option-notice --option=<lease ref or id>`.

Open the draft and check it against the lease: how notice must be given, to which address, by whom it is signed, and the last day. Tell the operator the file path and the last day. A person serves it the way the lease requires. Nothing is sent from here.
