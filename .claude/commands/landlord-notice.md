---
description: Record a landlord's notice, either the Victorian section 28 option notice or the NSW section 44 expiry notice.
---

For a Victorian retail lease option: `npm run lease -- landlord-notice --option=<lease ref> --on=<date received> --actor="<name>"`.
For a NSW retail lease nearing expiry: `npm run lease -- landlord-notice --lease=<ref> --on=<date received> --actor="<name>"`.

Ask for the date on the notice and keep a copy with the lease. Say what the notice changes, from `docs/compliance.md`.
